管理你的资源

配置 Harness

选择一个 Active Harness，或按本地配置创建。已归档的 Harness 不能用于新 Session。

配置 Environment

选择执行环境、Ready 的 SERVERLESS_PG SessionStore 和绑定该存储的运行模板，再选择匹配的 API Key。

密钥列表仅显示本机持有明文且绑定所选 Endpoint 与 Environment 的 Key。新资源准备好后可点击“刷新资源”。先创建 SessionStore，再创建 RuntimeTemplate。已有未绑定存储的旧模板仍可在 Session 管理页使用。

开始第一次调用

确认资源后创建 Session，然后在聊天页输入消息，查看模型回复与工具事件。
