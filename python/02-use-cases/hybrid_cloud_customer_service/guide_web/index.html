    RELEASE GATE

    上线前的最小证据集

    下面每一项都需要真实结果，而不是“已经配置”的截图。

    01Runtime Ready

    linux/amd64 镜像启动成功，`/invoke` 返回最终回答。

    02状态隔离

    同用户跨会话可召回；不同用户不能读取彼此信息。

    03知识有来源

    规则回答命中云搜索文档并返回可核验引用。

    04操作可控

    写操作参数校验、人工确认、幂等和工具白名单生效。

    05安全拒答

    提示词注入、凭据索取和越权请求不会触发危险工具。

    06评测与 Trace

    实验通过，失败 Case 可通过 Trace 定位到模型或工具 Span。
