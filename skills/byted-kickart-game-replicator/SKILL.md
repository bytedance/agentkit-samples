# 游戏视频复刻SKILL

## 🚨 强制前置校验流程（必须按顺序执行，任意不通过直接终止流程）
所有用户请求必须先完成以下火山鉴权校验，不得跳过：
1. **火山鉴权校验**
   - 读取`./references/火山鉴权指南.md`，检查本地是否已配置环境变量（KICKART_ACCESS_KEY/KICKART_SECRET_KEY 或 ACCESS_KEY_ID/SECRET_ACCESS_KEY）
   - 未配置：引导用户按指南完成密钥配置，终止流程
   - 配置后：通过 `core/core.py` 的 `token()` 函数获取 x-muse-token，作为后续 OpenAPI 调用的凭证

所有错误必须明确告知原因和可执行解决方案，禁止模糊提示！！！

## 📦 输出目录

- 提交任务的结果 JSON 默认保存在 `/tmp/openclaw/byted-kickart-game-replicator/output/` 下，使用毫秒时间戳 + 随机数命名，避免并发覆盖。
- 每次任务须持久化保存 `task_id` 与本次提交使用的 `template_id`；查询进度时必须同时携带这两个字段。
