# 抖音/短视频游戏视频复刻、克隆工具指南

## 触发场景
当用户需要复刻或克隆游戏视频，提到「游戏视频裂变」「游戏视频克隆」「复制游戏视频」「克隆游戏视频」「同款游戏视频」等，或者表达希望制作和某热门游戏视频一样的内容的等价意图时使用本工具。

## 执行流程
### Phase 0: 初始化（提交前确认）
在执行游戏视频复刻任务前，必须依次引导用户完成以下准备工作：

1. **参考视频获取（必填）**：向用户发送话术："好的，我帮你创建游戏视频复刻项目。请先提供 参考视频：可以发我视频链接，或上传 MP4/MOV 文件（>5s 且 ≤60s、≤50MB、分辨率 ≥480p，画面比例支持 9:16 / 16:9 / 3:4 / 4:3 / 1:1）"。然后阅读 `references/视频参考指南.md`，引导用户提供或上传参考视频，获取参考视频的素材ID作为 `ref_video`。成功获取后，必须明确记录状态已流转至下一步。
2. **角色图片获取（必填）**：参考视频获取成功后，遵循 `references/数字形象指南.md` 中规定的标准话术，引导用户上传 1-10 张角色图片，映射为 `role_images` 参数（多张素材ID使用逗号分隔）。要求：JPEG/PNG，单张 ≤8MB，单张分辨率 ≥480p，图片长宽比在 (0.4, 2.5) 之间，宽高像素范围在 (300, 6000) 之间。**至少 1 张角色图片是必填的，未完成前严禁提交任务**。成功获取后，必须明确记录状态已流转至下一步。
3. **游戏名称确认（必填）**：向用户发送话术："请告诉我这个游戏的名称，用于故事板生成方向（≤500 字符）"。根据用户回复，映射为 `game_name` 参数。成功确认后，必须明确记录状态已流转至下一步。
4. **语言设置确认（必填）**：向用户发送话术："请问成片视频需要使用什么语言？支持：中文(zh)、英文(en)、英语-美国(en-us)、巴西葡萄牙语(pt-br)、日语(ja)、西班牙语-墨西哥(es-mx)、印尼语(id)、马来语(ms)、他加禄语(tl)，默认使用中文(zh)"。根据用户选择，设置 `language` 参数。成功确认后，必须明确记录状态已流转至下一步。
5. **场景参考图（可选）**：向用户发送话术："如果希望指定视频中的场景，可以提供 0-3 张模型参考图（JPEG/PNG，单张 ≤8MB，分辨率 ≥480p），不提供则由系统智能匹配"。根据用户回复，若提供则映射为 `location_images` 参数（多张素材ID使用逗号分隔）。可以跳过此步骤。
6. **创意 Prompt（可选）**：向用户发送话术："如果你有自定义创意策略/爆点描述（≤5000 字符），可以现在告诉我，用于指导故事板生成方向；不填则使用系统默认策略"。根据用户回复，若提供则映射为 `prompt` 参数。可以跳过此步骤。
7. **模板 ID 确认（必填）**：向用户展示所有可选模板及含义：
   - `604911874`：专业模式（2.0、720p）
   - `463631106`：进阶模式（2.0fast、720p）
   必须要求用户本次提交明确输入一个 `template_id`。不能跳过，不能由技能自行选择，不能记忆或复用用户之前选择的 `template_id`。根据用户本次明确输入的内容，映射为 `template_id` 参数。
8. **展示成片信息（强制不可跳过）**：在收集齐上述所有必要参数并准备正式提交任务之前，必须先读取创意分析的结果（`input`）以及相关的视频参考信息，按照以下格式向用户展示即将生成的成片信息，询问用户是否符合预期。

> 🚨 **强制要求**：此步骤不可因为鉴权失败重试、参数调整、会话恢复或其他任何原因跳过。即使用户之前已确认过，每次提交新任务前都必须重新展示。

**播报模板示例（严格使用普通正文格式展示，保留换行，具体内容需从上文的分析结果中提取填充）：**
```text
视频成片信息如下，请进行确认：
- 游戏名称：[用户输入的 game_name，如 GTA]
- 成片时长：[默认按照输入参考视频的时长填充，如 15s]
- 语种：[默认中文，支持用户指定多语种，如英文、巴西葡萄牙语]
- 角色形象：[基于用户上传的角色图数量与内容概述，如：2 张自定义角色图]
- 场景：[从场景参考图或创意分析结果提取的场景，如：城市街道、赛车追逐]

👉 请确认以上成片信息是否符合您的预期？
```
9. **二次确认与合规提示（强制不可跳过）**：当用户明确回复成片信息符合预期后，必须进行二次确认，明确告知扣费风险及合规要求。等待用户明确回复确认或同意后，才可进入提交任务（Phase 1）环节。

> 🚨 **强制要求**：此步骤不可因为鉴权失败重试、参数调整、会话恢复或其他任何原因跳过。即使用户之前已确认过，每次提交新任务前都必须重新进行二次确认。

**二次确认播报模板示例（保留换行）：**
```text
⚠️ 本次任务将会消耗创点，任务发起后创点消耗不可退还。
请确认您已经阅读并同意了 [虚拟人像合规承诺函](https://www.volcengine.com/docs/6664/2369812?lang=zh) 和 [合规承诺函](https://www.volcengine.com/docs/6664/2369383?lang=zh)。

👉 确认请回复我，我将立即为您开始制作视频~
```

### Phase 1: 提交任务
用户确认生成后执行以下操作：
1. 确保输出目录存在：
   ```bash
   mkdir -p /tmp/openclaw/byted-kickart-game-replicator/output
   ```
2. 生成唯一输出文件名：
   ```bash
   VIDEO_FILE="/tmp/openclaw/byted-kickart-game-replicator/output/video_$(date +%s%N | cut -b1-13)_$((RANDOM%900000+100000)).json"
   ```
3. 提交生成任务（`--template-id` 为必填，取值必须是用户本次明确输入的模板 ID；`--role-images` 支持逗号分隔多张；`--location-images`、`--prompt` 为可选，未提供时不要传入对应参数）：

   ```bash
   python3 scripts/submit.py replication \
     --ref-video <ref_video素材ID> \
     --role-images <role_images素材ID,多张逗号分隔> \
     --game-name <游戏名称> \
     --language <语种代号> \
     [--location-images <场景图素材ID,多张逗号分隔>] \
     [--prompt <自定义策略>] \
     --template-id <604911874|463631106> \
     --output "$VIDEO_FILE"
   ```

   *(语种代号：`zh` 中文、`en` 英文、`en-us` 英语-美国、`pt-br` 巴西葡萄牙语、`ja` 日语、`es-mx` 西班牙语-墨西哥、`id` 印尼语、`ms` 马来语、`tl` 他加禄语。默认使用中文时可不传，即 `zh`。)*
4. 脚本会自动通过 `core/core.py` 获取 x-muse-token，并调用 `core/api/call_api.py` 提交任务和轮询结果
5. 如果提交返回错误，根据错误码补充缺失的参数后重试，最多重试 3 次

### Phase 2: 提交后回复
脚本将自动提交任务并进行轮询查询进度。如果轮询期间任务完成，结果会直接保存到 `output` 文件中，请直接向用户播报结果。
如果在轮询期间未完成（命令行提示"任务正在执行中"），从输出中提取返回的任务 ID 和本次调用的 `template_id`，并按照以下模板回复用户：
```txt
✅ 游戏视频复刻任务已提交成功，任务ID:<任务ID>；本次调用的template_id:<template_id>
⚠️ 任务正在后台执行中，您可以随时通过「查询进度」来获取最新状态~ 🦞
```
如果提交返回错误，需严格按照全局 `SKILL.md` 中的【错误处理规范】匹配对应的错误码，并按照以下模板回复用户建议：
```txt
❌ 游戏视频复刻任务提交失败(任务ID:<任务ID>，template_id:<template_id>)
- 错误码:<返回的错误码>
- 处理建议:<匹配 SKILL.md 错误处理规范中的用户处理建议>
```

```txt
游戏视频复刻成功！请点击链接预览或下载视频：[视频](<提取到的视频URL>)
```
