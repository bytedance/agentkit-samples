# 火山引擎鉴权操作指南
## 用途说明
本指南用于指导 agent 完成火山引擎 API 调用前的身份鉴权校验，确保访问密钥配置正确可用（支持 KICKART_ACCESS_KEY/KICKART_SECRET_KEY 或 ACCESS_KEY_ID/SECRET_ACCESS_KEY 两种命名方式），并获取 x-muse-token 作为后续 OpenAPI 调用的凭证。

---

## 🚀 鉴权操作流程（必须严格按顺序执行）
### 步骤 1：执行环境变量检查命令
直接运行以下命令，检查鉴权配置：
```bash
echo "KICKART_ACCESS_KEY: $KICKART_ACCESS_KEY" && echo "KICKART_SECRET_KEY: $KICKART_SECRET_KEY" && echo "ACCESS_KEY_ID: $ACCESS_KEY_ID" && echo "SECRET_ACCESS_KEY: $SECRET_ACCESS_KEY"
```

### 步骤 2：判断鉴权结果
1. **鉴权通过**：如果 `KICKART_ACCESS_KEY` 和 `KICKART_SECRET_KEY` 均为非空值，或者 `ACCESS_KEY_ID` 和 `SECRET_ACCESS_KEY` 均为非空值，鉴权通过（优先使用 KICKART_ 前缀的环境变量）
2. **鉴权不通过**：若不满足上述条件，说明未配置或配置无效，进入「未配置引导流程」

### 步骤 3：获取 x-muse-token
鉴权通过后，运行以下命令获取 x-muse-token：
```bash
python3 scripts/core/core.py
```
- Token 有效期为 12 小时，会自动缓存到 `/tmp/kickart/.token`
- 后续所有 OpenAPI 调用（提交任务、查询任务）都会自动使用缓存的 token

---

## ❌ 未配置时的引导方案
1. 引导用户直接在聊天中发送 AK/SK 内容：
   > 直接在此处发送您的 Access Key ID 和 Secret Access Key，我会帮您完成临时环境变量配置
2. 收到用户发送的 AK/SK 后，执行配置命令：
   ```bash
   export KICKART_ACCESS_KEY=用户提供的 Access Key ID 值
   export KICKART_SECRET_KEY=用户提供的 Secret Access Key 值
   ```
3. 配置完成后告知用户：
   > 已完成 AK/SK 临时配置，当前配置仅在本次会话生效，不会持久化存储，请放心使用
4. 后续所有相关脚本执行时，均会自动通过 `export` 指定这两个环境变量，确保鉴权正常，无需用户重复配置


---

## ⚠️ 安全注意事项（强制遵守）
1. **敏感信息掩码处理**：用户提供的 AK/SK（Access Key ID/Secret Access Key）属于最高级敏感信息，写入数据库时必须全部替换为 `***` 掩码，禁止明文存储
2. **临时生效原则**：仅将 AK/SK 配置到当前进程的环境变量中，禁止写入任何本地文件、配置文档或持久化存储
3. **最小权限提示**：提醒用户使用最小权限的 AK/SK，避免使用主账号密钥，降低安全风险
4. **禁止泄露**：任何场景下都不得向第三方泄露用户的 AK/SK 内容，包括返回给用户的消息中也不得展示完整的 AK/SK
