# 视频发布指南

通过 `python publish.py` 生成抖音发布二维码和跳转链接，用户扫码即可快速进入抖音发布页面，视频和文案自动预填。

> **无需登录抖音账号**，生成的链接有效期 24 小时，手机端扫码或点击链接即可直接唤起抖音 APP。

## Quick Reference

| 参数 | 说明 | 必需 | 默认值 |
|------|------|------|--------|
| `--url` | 待发布视频的 URL 地址（必须可公网访问） | 是 | - |
| `--body` | 抖音发布文案内容 | 是 | - |
| `--output` | 生成的二维码图片保存路径 | 是 | 建议使用动态生成路径：<br>`/tmp/openclaw/kickart/output/qrcode_$(date +%s%N | cut -b1-13)_$((RANDOM%900000+100000)).png` |

## 使用示例

```bash
# 基础用法：生成抖音发布链接（自动生成唯一二维码路径）
QRCODE_FILE="/tmp/openclaw/kickart/output/qrcode_$(date +%s%N | cut -b1-13)_$((RANDOM%900000+100000)).png"
python publish.py --url "https://example.com/my-video.mp4" --body "这是我的作品，欢迎点赞关注👍" --output "$QRCODE_FILE"
```

## 使用流程决策

```
用户请求发布抖音视频
├─ 未提供视频 URL → 提示用户提供视频 URL
├─ 未提供发布文案 → 提示用户提供发布文案
├─ URL 格式不合法（非 http/https） → 提示用户提供合法 URL
└─ 信息完整 → 执行 python publish.py → 按标准模板输出二维码和跳转链接
```

## 标准输出模板

### 文字回复内容：
```
✅ 抖音发布链接已生成～
1. **扫码发布**：打开抖音 APP 扫描下方二维码，即可自动跳转至发布页面，视频和文案已预填完成
2. **链接发布**：在手机端点击下方跳转链接，直接唤起抖音 APP 进入发布页面
🔗 跳转发布链接：[点击发布](<跳转 URL>)

⚠️ 注意事项：
- 二维码和链接有效期均为 24 小时，请尽快使用
- 跳转发布后请自行检查视频和文案是否正确，确认无误后再点击发布
- 链接需要在手机端打开，PC 端无法唤起抖音 APP
```

### 发送方式（全平台兼容）：
通过 `message` 工具统一发送，通过 `channel` 参数适配不同平台：
```json
{
  "action": "send",
  "channel": "<平台标识>", // 可选，默认使用当前会话所在平台；支持 feishu/wechat/weibo/discord/telegram/webchat 等
  "message": "<上述文字内容>",
  "media": "<二维码文件路径>"
}
```

✅ 平台自动适配：
- 不指定 `channel` 时自动使用当前对话所在平台发送，无需额外配置
- 如需跨平台发送，显式指定对应 `channel` 值即可
- 所有平台均支持 `media` 参数上传图片，无需单独处理

通用原则：文字内容和二维码一次性发送，不要分开发送，不要内嵌二维码到文字内容中。

## Common Mistakes

| 错误 | 正确做法 |
|------|----------|
| 用户未提供文案就直接调用工具 | 用户未提供文案时，先提示用户补充完整，不调用命令 |
| 接受非 HTTP/HTTPS 的 URL | 必须校验 URL 格式，不合法要求用户重新提供 |
| 在 PC 端打开链接测试 | 提示用户必须在手机端打开链接才能唤起抖音 |
| 不提示有效期 | 必须按照模板输出注意事项，提醒用户尽快使用 |
| 用 MEDIA:xxx 语法内嵌图片 | 不要内嵌，必须将二维码作为单独图片附件发送 |
| 发送消息时漏传二维码 | 必须同时发送文字内容和二维码图片，不要只发链接 |
| 硬编码只支持单一平台 | 使用通用 `message` 工具+`channel` 参数自动适配多平台 |
| 分多次发送文字和二维码 | 单次调用 `message` 同时传 `message` 和 `media` 参数，一次性发送 |
