## 一、概述
本指南使用 `npm exec -y --package @volcengine/kickart-open-mcp@1.0.x kickart-open-cli query_task_v2` 查询爆款裂变任务的状态和结果。任务完成后默认自动发布成片到 KickArt，并返回本地响应 JSON 路径。**适用场景**：用户提及「查询进度」「查看结果」「生成怎么样了」「好了吗」等意图时，无需重复提交相同任务。

## 二、前置依赖
1. 已按 `CLI前置校验指南.md` 验证 `npm exec -y --package @volcengine/kickart-open-mcp@1.0.x kickart-open-cli` 可用且 OAuth 登录态有效。
2. 当前会话中存在有效 `task_id`，或用户明确提供了要查询的 `task_id`。

## 三、CLI 参数说明

执行命令时传入以下参数：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--task-id` | string | - | 提交成功时返回的任务 ID。 |
| `--source` | `"ad_variations" \| "kickart_ai_material"` | - | 本 Skill 固定传入 `ad_variations`。 |
| `--auto-publish` | boolean | `true` | 完成后是否自动发布结果视频；本 Skill 固定传 `true`。 |

`--source` 必须显式传 `ad_variations`，不得由用户改写。参数行为不确定时先执行 `npm exec -y --package @volcengine/kickart-open-mcp@1.0.x kickart-open-cli query_task_v2 --help`。

## 四、返回结果说明
### 轮询中输出
当 stdout JSON 中 `status = "running"` 时，展示 `task_id`、`progress` 和 `message`。后续查询仍由用户主动触发，不得自动轮询或重复提交任务。

### 成功返回
当 stdout JSON 中 `status = "completed"` 时，提取 `result_url`、`payload`、`usage`、`response_file_path` 和可选的 `published_media`。`--auto-publish true` 且存在结果 URL 时，优先同时告知发布后的媒资信息。

### 失败返回
当 stdout JSON 中 `status = "failed"` 时，反馈 `message` 并保留 `raw` 与 `response_file_path` 便于排查。命令非零退出时读取并脱敏 stderr。

## 五、调用示例
```bash
npm exec -y --package @volcengine/kickart-open-mcp@1.0.x kickart-open-cli query_task_v2 \
  --task-id 7619174133103902774 \
  --source ad_variations \
  --auto-publish true
```

## 六、注意事项
1. `query_task_v2` 使用任务 ID 查询爆款裂变任务，并固定使用 `--source ad_variations` 同步产品产物。
2. 每次查询都会把原始响应保存到 `response_file_path`。
3. `auto_publish = true` 时，任务完成后由工具发布成片到 KickArt。
4. 仅支持查询当前账号可访问的任务。
5. 任务结果存在时效限制，成功后应及时向用户提供下载链接。
6. 始终通过 `npm exec -y --package @volcengine/kickart-open-mcp@1.0.x kickart-open-cli` 调用固定版本；npm exec 获取包或启动 CLI 失败时，按 `CLI前置校验指南.md` 反馈错误并终止查询。

## 七、Agent执行流程（强制遵守）
1. **意图匹配优先级检查**：命中「查询进度/查看结果/生成怎么样了/好了吗」关键词时，优先触发本指南加载，禁止跳过直接执行其他逻辑
2. **任务ID持久化校验**：先校验当前主会话，再从该主会话上下文临时存储中获取用户提交的最近一次异步任务（爆款裂变/视频生成）对应的Task ID及关联信息（任务类型、提交时间、会话ID），若未获取到有效ID，直接告知用户「未查询到相关提交任务，请确认任务是否已提交」
3. **执行命令**：执行 `npm exec -y --package @volcengine/kickart-open-mcp@1.0.x kickart-open-cli query_task_v2 --task-id <ID> --source ad_variations --auto-publish true`。
4. **结果反馈规范**：
   - 任务执行中：告知用户当前任务类型、提交时间和进度，提示任务仍在后台执行。
   - 执行成功：解析 stdout JSON 和返回的本地 JSON 文件路径，提取成片链接后反馈用户。
   - 执行失败：明确告知用户错误原因和对应解决建议，如需重试可协助重新提交。
5. **禁止绕过 CLI**：命令失败时反馈脱敏后的 stderr，不得直接请求接口或使用内部 `poll` 命令。
