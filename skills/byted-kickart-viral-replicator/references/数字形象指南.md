# 数字形象指南

## 目的与适用场景
当用户在「爆款裂变」任务中，需要自定义模特图或指定角色出镜时使用本指南，引导用户提供并校验符合规范的角色图片。

## 图片规格要求
- **数量**：`1–3` 张
- **格式**：`JPEG` 或 `PNG`
- **单张大小**：`≤8MB`
- **分辨率**：`≥480p`
- **总像素 (宽 × 高)**：在 `9万` 到 `3600万` 之间
- **宽高比**：在 `0.25` 到 `4` 之间
- **合规限制**：严禁上传明星、公众IP形象。

## 交互方式与话术规范（强制遵守）
1. **引导提供图片**：
   在爆款裂变任务中收集完商品信息后，**必须严格按照以下话术**引导用户上传图片（需保持结构清晰、友好的格式）：
   > 💡 我为你智能匹配了数字人，如果你有想用的自定义数字人形象，也可以直接发图片给我哦！
   >
   > ⚠️ **上传注意事项**：
   > 1️⃣ **数量限制**：最多可上传 3 张图片；
   > 2️⃣ **形象一致**：若上传多张图片且人物形象不一致，将默认选择第 1 张的人物形象；
   > 3️⃣ **合规要求**：请勿上传明星、公众IP等侵权形象。

   **⚠️ 重要规范**：
   - **禁止使用其他话术**：不得使用"是否需要添加自定义模特"等询问式话术，必须使用上述标准话术
   - **禁止提及尺寸要求**：不得提及"500*500px"等具体尺寸要求，以指南中的规格为准（分辨率≥480p，总像素9万-3600万）
   - **禁止使用"继续下一步流程"等催促性语言**：话术中不得出现催促用户继续流程的表述

2. **接收多张图片**：
   - 当用户上传新的数字人形象图片时，**默认追加到现有数字人形象列表中**，除非用户明确说明「替换原有形象」才覆盖之前的ID。
   - 总数量限制为最多3张：当前列表 + 新上传图片总数 ≤3时全部保留；超过3张时，**明确告知用户已达到3张上限**，并请用户选择保留哪3张，或指定要替换的原有形象。
   - 所有有效形象按上传顺序排列，第一张为默认使用的数字人形象。
   - **主动询问继续上传**：每次成功处理并保存用户的数字人图片后，如果当前收集到的图片不足3张，**必须主动询问用户是否还需要继续上传其他角度/形象的图片**。只有当用户明确确认不再上传（或已经达到3张上限）时，才结束图片收集环节并进入下一步。

3. **错误/超限提示**：
   如果用户上传的图片不符合规格要求（工具返回错误），必须明确指出具体超限数值，并引导用户重新提供。例如：
   > 这张图片大小 15MB 超过 8MB 限制，请压缩或换一张再发我
   *(注意：请根据实际的超限指标灵活替换上述模板中的字段)*

## 图片处理流程
获取用户图片后，完成基础校验并保留可直接传给 `npm exec -y --package @volcengine/kickart-open-mcp@1.0.x kickart-open-cli submit_viral_task_v2 --model-images` 的本地绝对路径或公网 URL：

### 步骤1：识别输入

- **用户提供公网图片 URL**：校验 URL 使用 HTTP(S) 协议并保留原始 URL，无需下载或上传。
- **用户上传本地图片文件**：获取 CLI 进程可读取的文件绝对路径。

### 步骤2：基础校验

本地图片不预先调用素材上传工具。提交前至少校验：

- 路径是 CLI 进程可读取的绝对路径，且文件存在。
- 扩展名为 `.jpg`、`.jpeg` 或 `.png`。
- 单张大小不超过 8MB，总数量为 1–3 张。
- 能够获取图片元数据时，继续校验分辨率 ≥480p、总像素在 9万–3600万之间、宽高比在 0.25–4 之间。
- 无法在本地确认图片元数据时保留该素材，由 `submit_viral_task_v2` 做最终服务端校验；不得声称已通过无法执行的校验。
- 明确提醒并要求用户确认图片不包含明星、公众 IP 等侵权形象。

### 步骤3：提取并保留结果

- 本地图片保留绝对路径，公网图片保留原始 URL。
- 多张图片按用户提供顺序保存为字符串数组，不得拼接为逗号分隔字符串。
- 执行 `submit_viral_task_v2` 时，通过 `--model-images` 传入素材，具体多值语法以 `--help` 为准，由 CLI 自动上传本地文件并转换为 URL。
- 保持已有追加/替换交互规则；新增图片后重新校验总数量不得超过 3 张。

### 步骤4：提交前校验

提交前必须确认每张本地图片仍存在且可读、绝对路径有效、格式和大小符合限制，并已完成合规确认。任一素材失败时不得提交任务，应明确失败图片、实际值、限制和解决方案。校验通过后不执行 `material_pipeline_v2`，由 `submit_viral_task_v2` 自动完成本地素材上传。
