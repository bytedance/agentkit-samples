# 资质申请向导

按 [qualification-display.md](qualification-display.md) 打开私密向导，由客户在页面填写
和上传材料。Agent 保留同一个前台会话，持续读取结果；页面维护草稿、材料和校验状态。

## 材料要求

必填项以页面读取的账号规则为准：

| 材料 | 规则 |
| --- | --- |
| 资质名称 | 选填，最多 20 字；未填时使用营业证件名称 |
| 营业证件 | 照片是否必填由账号规则决定；企业信息可经 OCR 回填后修改，法人姓名必填 |
| 法人补充信息 | 身份证号、手机号和身份证图片均由客户按需选填；图片需正反两面 |
| 经办人与独立责任人 | 姓名、身份证号必填；照片和手机号按账号规则填写 |
| 责任人与经办人相同 | 在页面选择相同，复用经办人材料和校验结果 |
| 他用授权材料 | 规则要求时上传一张委托书；授权方取营业证件名称，被授权方取账号主体 |
| 其他材料 | 选填，最多五张 |

图片支持 JPG、JPEG、PNG，单张不超过 10 MB。身份证分别上传人像面、国徽面；复印件
或黑白营业证件按页面提示盖章。

## 校验与提交

客户在页面完成材料校验与账号要求的手机验证。企业信息不匹配或校验接口失败时，页面
展示接口错误和排障编号，写入兼容校验票据后可按提示转人工审核；人员信息校验通过后
继续，填写法人居民身份证号时执行对应校验。
材料修改后重新保存和校验，以当前草稿生成最终预览。客户核对并勾选后提交一次，
成功返回申请 ID，再查询审核状态。确定的校验失败由客户在原页面修改；结果未知时
保留申请与诊断标识，查询核实。“放弃本次填写”结束未提交的本地草稿，线上申请状态另行查询。

## 结果与排障

前台会话的 `QUALIFICATION_EXCHANGE` 和 `QUALIFICATION_FAILURE` 提供阶段、错误码、
HTTP 状态、Request ID 和 Log ID。个人信息经掩码展示，图片地址、凭证和校验票据仅展示存在状态。
最终结果包含申请 ID、状态、草稿版本及诊断标识；完整材料由页面和本机脚本保管。
页面失联或关闭时向导结束服务，展示问题按 [qualification-display.md](qualification-display.md)
处理，业务问题依据接口错误处理。
