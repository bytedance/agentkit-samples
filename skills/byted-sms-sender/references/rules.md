# 跨流程规则

## 授权

- 预览只对当前命令和当前字段有效，不持久化。
- 申请预览覆盖全部提交字段；发送预览覆盖资源、收件人、变量、内容摘要和预计条数；
  群发启动预览覆盖任务、文件指纹、号码统计和发送时间。
- 字段变化立即使授权失效；写请求发出后本次授权视为已消耗。
- 单条发送必须明确授权；群发启动必须完全匹配 `确认启动任务 <taskId>`。

## 客户资源与输入

- 只使用当前身份可见且审核通过的消息组、资质、签名和模板。
- 签名输入不包含外围括号；模板变量与内容和执行值完全一致。
- 中国大陆手机号比较前归一为 11 位，输出只保留前三位和后四位。
- 客户明确要求群发时，不因号码少而改用单条发送。
- CSV 使用 `phone` 列；XLSX 只有依赖明确存在时才支持，禁止静默按 CSV 解析。
- 不持久化上传文件、预签名 URL 或授权摘要。

## 脱敏

- 完全移除 AK/SK、Session Token、Authorization、校验 ticket 和上传凭证。
- 所有手机号、证件号和姓名按资质参考文件掩码；验证码和敏感模板变量不回显。
- 图片、文件内容和材料地址不进入对话；URL 去除查询参数及 fragment。
- 通用 CLI 只返回客户可见字段；资质诊断遵循
  [qualification-materials.md](qualification-materials.md)。

## 重试与对账

- 查询共享 [actions.md](actions.md) 定义的有界重试预算。
- 写操作只发送一次。只有确定请求尚未发出时才允许切换调用路径；超时、非结构化结果
  或响应丢失都返回 `outcome_unknown`。
- 签名和模板申请通过资源查询对账；群发通过任务详情；发送仅使用已知 Message ID 的
  日志。没有安全唯一键时不按内容或模糊时间窗猜测。
- 证据不足时不猜成功或失败。

## 查询预算

- 聚合分桶与发送日志分页在重试前合计不超过 120 次逻辑查询。
- 查询必须有限分页；50 QPS/账号 5 QPS 是上限，不是自动重试额度。
