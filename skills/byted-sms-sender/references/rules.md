# 授权与结果处理

申请、发送和任务启动依据客户确认的当前预览执行；内容、名单或时间改变后重新预览。
群发先创建待确认任务，再启动同一个 taskId；CLI 授权文字为 `确认启动任务 <taskId>`。

当前身份的可用资源由接口核实，材料和号码名单由私密表单或本机脚本处理。
对话返回业务摘要、公开错误码和 Request ID；凭据、上传地址及完整个人资料留在本机。

写请求明确拒绝时按原因修改，再准备新预览；超时或响应丢失时先查询原请求结果。
申请结合资源查询核实，证据不足时保留未知；群发按 taskId，单条发送按 Message ID 查询。
脚本负责查询重试和写入去重；证据不足时报告结果待核实。
