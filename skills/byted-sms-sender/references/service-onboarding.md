# 短信服务开通引导

只在只读短信接口明确返回公开错误码 `RE:0001` 时使用本文。该错误表示当前调用身份
对应的账号尚未开通短信服务。空消息组、无资质、无签名/模板、`RE:0000`、欠费、
账号关停或普通权限错误都不是服务未开通，不得进入本流程。

## 引导流程

1. 优先使用可复用客户登录态的浏览器能力，自动打开火山引擎短信控制台：
   <https://console.volcengine.com/sms>。
2. 若页面要求登录，引导客户在页面内完成账号登录；不要再次发起 CLI 登录，也不要
   要求其输入终端命令或提供 AK/SK。
3. 定位页面上的短信服务自助开通入口。只向客户说明：
   “短信服务还没有开通。我已为你打开官方开通页，请阅读协议并点击同意开通；完成后
   我会继续处理刚才的短信任务。”
4. 服务协议及可能涉及的计费条款必须由客户亲自阅读、勾选并确认。Agent 可以导航和
   解释页面，但不得代替客户同意协议或点击最终开通按钮。
5. 客户完成开通，或 Agent 能从页面确认开通成功后，重新执行一次只读
   `list-message-groups`。成功即恢复原任务；仍返回 `RE:0001` 时说明开通状态尚未
   生效，保留原任务上下文并停止，不循环刷新。

无法控制浏览器时，只给客户一个可点击的
[短信服务控制台](https://console.volcengine.com/sms)链接和第 3 步的单句提示；不要
展示错误码、诊断过程、多种方案或控制台菜单教程。

## 边界

- 开通服务不代表已经具备发送条件。后续仍按主流程检查消息组、资质、签名和模板。
- 没有已审核资质时，按 `qualification-materials.md` 打开本机资质向导；不得在对话中
  收集图片或个人材料。
- 如果 `RE:0001` 来自已经获得授权的写操作，视为该次操作失败并停止。服务开通后
  从新的预览和授权开始，不自动重放原请求。
